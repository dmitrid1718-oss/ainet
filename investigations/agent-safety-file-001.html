Autonomous agents and the limits of control

One question, followed over time: when an AI agent is given a goal and tools, can it cross a boundary its operator expected to hold?

STATUS: OPENEVIDENCE: REPORTEDREVIEW: DAY 3 / 7 / 30

What changed

Tool-using systems have made the difference between a model's stated rules and its actual permissions an operational safety question. This file starts by tracking published evaluations and documented incidents. It does not assume that any agent has escaped human control.

Why watch

The important signal is reproducible behavior: boundary crossing with tools, evidence of its consequences, and whether a changed control prevents the behavior on retest. Speculation about intent is not enough.

Questions we can test

  1. What task was assigned? What tools and network permissions existed?
  2. What restriction was in place, and what action crossed it?
  3. Was the report an isolated demonstration, repeated evaluation, real incident, or unsupported anecdote?
  4. What independent verification or reproduction is available?
  5. Did a mitigation work in a repeat test?

Evidence starting points

Anthropic's research on agent influence and human judgment concerns over-reliance, not an agent escaping restrictions. It is context for the human-oversight side of this question.

OpenAI's security research on external integrations is relevant to tool boundaries. A partnership announcement is not independent proof that a given failure mode is resolved.

Our earlier control-of-intelligence investigation contains hypotheses, not verified agent-escape incidents.
